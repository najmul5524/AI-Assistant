# 🤖 24/7 Free Multi-Tier AI Assistant

একটি সম্পূর্ণ ফ্রি, ২৪ ঘণ্টা সচল এবং মাল্টি-লেয়ার (Failover) পার্সোনাল এআই অ্যাসিস্ট্যান্ট। এটি টেলিগ্রামের মাধ্যমে পরিচালিত হয় এবং একটি এআই প্রোভাইডারের ফ্রি লিমিট শেষ হলে স্বয়ংক্রিয়ভাবে পরবর্তী প্রোভাইডারে সুইচ করে কাজ সম্পন্ন করে।

---

## 🌟 মূল বৈশিষ্ট্যসমূহ (Key Features)

1. **Multi-Tier AI Fallback Engine:**
   - **Tier 1 (Primary):** Google Gemini 2.0 / 1.5 Flash (Free Tier)
   - **Tier 2 (Failover):** Groq Cloud - LLaMA 3.3 70B (Free Tier, আল্ট্রা ফাস্ট)
   - **Tier 3 (Backup):** OpenRouter Free Models (DeepSeek R1 / LLaMA)
   - *কোনো একটিতে কোটা শেষ হলে বা এরর আসলে কোড স্বয়ংক্রিয়ভাবে পরবর্তিটায় সুইচ করে। ইউজারকে কোনো কিছু ম্যানুয়ালি করতে হয় না।*
2. **টেলিগ্রাম ইন্টারফেস:**
   - মোবাইল বা কম্পিউটার—যেকোনো স্থান থেকে ২৪ ঘণ্টা মেসেজ দিয়ে কাজ করানো যায়।
   - **Security Whitelist:** শুধু আপনার Telegram User ID ছাড়া অন্য কেউ এটি ব্যবহার করতে পারবে না, ফলে আপনার ফ্রি কোটা থাকবে নিরাপদ।
3. **স্মার্ট মেমোরি (Persistent Memory):**
   - SQLite ডেটাবেসে পূর্ববর্তী কথোপকথন সংরক্ষিত থাকে, ফলে বট আগের কথা মনে রাখে।
4. **লাইভ ফ্রি ওয়েব সার্চ:**
   - DuckDuckGo সার্চ ইন্টিগ্রেশন (১০০% ফ্রি, কোনো API key লাগে না)।
5. **২৪/৭ শিডিউলড রিমাইন্ডার:**
   - যেকোনো কাজের রিমাইন্ডার সেট করলে নির্দিষ্ট সময়ে বট আপনাকে সরাসরি টেলিগ্রামে মেসেজ পাঠাবে।

## 🚀 ধাপে ধাপে সেটআপ গাইডলাইন (Beginner's Setup Guide)

### ধাপ ১: ফ্রি টেলিগ্রাম বট টোকেন নেওয়া (১ মিনিট)
1. টেলিগ্রাম অ্যাপে গিয়ে সার্চ করুন **`@BotFather`**
2. `/newbot` লিখে সেন্ড করুন।
3. আপনার বটের জন্য একটি নাম ও ইউজারনেম দিন (যেমন: `my_personal_ai_bot`)।
4. BotFather আপনাকে একটি **HTTP API Token** দেবে (যেমন: `7829103819:AAH...`)। এটি কপি করে রাখুন।

### ধাপ ২: আপনার নিজের Telegram User ID জেনে নেওয়া
1. টেলিগ্রামে সার্চ করুন **`@userinfobot`**
2. স্টার্ট চাপলে আপনার একটি ইউনিক `Id` দেখতে পাবেন (যেমন: `123456789`)।
3. এটি কপি করুন। এটি `.env` ফাইলে দিলে অন্য কেউ আপনার বটের কোটা নষ্ট করতে পারবে না।

### ধাপ ৩: ফ্রি এআই কী (API Keys) সংগ্রহ করা
1. **Google Gemini API Key (Tier 1):**
   - যান: [https://aistudio.google.com/](https://aistudio.google.com/)
   - আপনার গুগল অ্যাকাউন্ট দিয়ে লগইন করে **"Get API key"**-তে ক্লিক করে একটি ফ্রি কী তৈরি করুন।
2. **Groq Cloud API Key (Tier 2):**
   - যান: [https://console.groq.com/](https://console.groq.com/)
   - ফ্রি অ্যাকাউন্ট খুলে **"API Keys"** সেকশন থেকে একটি কী তৈরি করুন (এটি সুপারফাস্ট LLaMA 3.3 চালায়)।
3. *(ঐচ্ছিক)* **OpenRouter Key (Tier 3):**
   - যান: [https://openrouter.ai/](https://openrouter.ai/)

### ধাপ ৪: প্রজেক্ট কনফিগার করা

প্রজেক্ট ফোল্ডারে `.env.example` ফাইলের নাম পরিবর্তন করে `.env` করুন অথবা একটি নতুন `.env` ফাইল বানিয়ে নিচের তথ্যগুলো বসিয়ে দিন:

```env
# আপনার টেলিগ্রাম বটের টোকেন
TELEGRAM_BOT_TOKEN=your_telegram_bot_token_here

# আপনার টেলিগ্রাম আইডি (নিরাপত্তার জন্য)
ALLOWED_USER_IDS=123456789

# ফ্রি এআই কী-সমূহ
GEMINI_API_KEY=your_gemini_key_here
GROQ_API_KEY=your_groq_key_here
OPENROUTER_API_KEY=your_openrouter_key_here

BOT_NAME=Nova AI
DEFAULT_TIMEZONE=Asia/Dhaka
```

### ধাপ ৫: রান করা (Windows / Local)

টার্মিনালে প্রজেক্ট ফোল্ডারে গিয়ে ডিপেন্ডেন্সি ইন্সটল করুন:

```bash
pip install -r requirements.txt
```

সিস্টেম টেস্ট করতে:
```bash
python test_assistant.py
```

বট চালু করতে:
```bash
python bot.py
```

ব্যাস! এখন টেলিগ্রামে আপনার বটকে `/start` লিখে মেসেজ দিন।

## 🎙️ ভয়েস মেসেজ ও ভয়েস রিপ্লাই (Voice-to-Voice Interaction)

বটটিতে আল্ট্রা-ফাস্ট **Groq Whisper-large-v3** (স্পিচ-টু-টেক্সট) এবং **Microsoft Edge Neural TTS** (টেক্সট-টু-স্পিচ) ইন্টিগ্রেশন রয়েছে:
* **ভয়েসে প্রশ্ন করুন:** টেলিগ্রামে মাইক (🎙️) চেপে ধরে মুখে কথা বলে প্রশ্ন বা নির্দেশ পাঠান।
* **ভয়েসে উত্তর শুনুন:** বট আপনার কথা শুনে সাথে সাথে টেক্সট উত্তর দেওয়ার পাশাপাশি সাবলীল বাংলা কণ্ঠে একটি **অডিও ভয়েস নোট** পাঠিয়ে দেবে!
* 🗣️ *"গোল্ডের ক্যান্ডেল ব্যবচ্ছেদ করে সিগনাল দাও"* — সাথে সাথে 15m ক্যান্ডেল অ্যানাটমি ও এন্ট্রি/SL/TP সেটআপের সাথে ভয়েস ব্রিফিং দেবে।
* 🗣️ *"আমাকে ২০ মিনিট পর চা খাওয়ার রিমাইন্ডার দাও"* — স্বয়ংক্রিয়ভাবে রিমাইন্ডার সেট হয়ে যাবে।
* 🗣️ *"আজকের ফরেক্স নিউজ কি কি আছে বলো"* — আজকের ক্যালেন্ডার ইভেন্ট ব্রিফিং দেবে।
* 🗣️ *"আর্টিফিশিয়াল ইন্টেলিজেন্স নিয়ে একটা এক্সিকিউটিভ রিপোর্ট বানিয়ে দাও"* — সরাসরি PDF ফাইল বানিয়ে টেলিগ্রামে পাঠিয়ে দেবে।

## 📌 টেলিগ্রাম কমান্ডসমূহ

* `/voice [on|off|female|male]` — ভয়েস রিপ্লাই কনফিগারেশন (`/voice on` দিয়ে প্রতিটি উত্তরের সাথে অডিও ভয়েস চালু, `/voice female` দিয়ে নবনিতা বা `/voice male` দিয়ে প্রদীপ কণ্ঠ নির্বাচন)।
* `/ta [সিম্বল] [টাইমফ্রেম]` — লাইভ ক্যান্ডেলের নিখুঁত ব্যবচ্ছেদ (Dissection), ইন্ট্রা-ক্যান্ডেল গঠন (Early/Mid/Late), পূর্ববর্তী High/Low সুইপ বনাম ব্রেকআউট এবং এন্ট্রি, SL ও TP1/TP2 সহ প্রাতিষ্ঠানিক সিগন্যাল (যেমন: `/ta`, `/ta btc`, `/ta gold 5m`, `/ta eurusd 1h`)।
* `/forecast` বা `/prediction` বা `/digest` — সারাদিনের সমস্ত নিউজ, গোল্ড, সিলভার, ফিউচার্স ও ক্রিপ্টো সেন্টিমেন্ট বিশ্লেষণ করে আগামীকালের প্রাতিষ্ঠানিক প্রাইস রেঞ্জ পূর্বাভাস।
* `/forecast_pdf` — আগামীকালের মার্কেট পূর্বাভাস ও টেকনিক্যাল চার্টসহ প্রাতিষ্ঠানিক চিত্রায়িত PDF রিপোর্ট।
* `/forex_pdf` — সরাসরি পূর্ণাঙ্গ প্রাতিষ্ঠানিক সাপ্তাহিক ফরেক্স ইন্টেলিজেন্স PDF রিপোর্ট তৈরি ও ডাউনলোড।
* `/news` — সর্বশেষ ব্রেকিং ফরেক্স নিউজ ও তাৎক্ষণিক এআই মার্কেট ইমপ্যাক্ট এনালাইসিস।
* `/forex` — আজকের High & Medium Impact ফরেক্স ক্যালেন্ডার নিউজ দেখা।
* `/forex_sync` — আজকের ফরেক্স ক্যালেন্ডার Google Calendar-এ রিমাইন্ডার অ্যালার্টসহ স্বয়ংক্রিয়ভাবে সিঙ্ক করা।
* `/report <বিষয়>` — যেকোনো বিষয়ে প্রফেশনাল এক্সিকিউটিভ PDF রিপোর্ট তৈরি (যেমন: `/report এআই মার্কেট ২০২৬`)।
* `/email <প্রাপক> <বিষয়> | <বার্তা>` — আসল প্রফেশনাল ইমেইল পাঠানো।
* `/status` — কোন কোন AI মডেল সক্রিয় আছে এবং সিস্টেমের অবস্থা দেখাবে।
* `/search <বিষয়>` — লাইভ ওয়েব সার্চ করে তথ্য দেবে (যেমন: `/search আজকের আবহাওয়া ঢাকা`)।
* `/remind <মিনিট> <কাজ>` — নির্ধারিত সময় পর আপনাকে টেলিগ্রামে অ্যালার্ট দেবে (যেমন: `/remind 20 ঔষধ খেতে হবে`)।
* `/reminders` — বর্তমান অপেক্ষমান রিমাইন্ডারগুলোর তালিকা।
* `/time` — বর্তমান রিয়েল-টাইম লাইভ ঘড়ি।
* `/clear` — পূর্ববর্তী চ্যাট ইতিহাস মুছে দিয়ে ফ্রেশ শুরু করবে।
* `/help` — ব্যবহারের নির্দেশিকা।

## ☁️ ২৪/৭ সম্পূর্ণ ফ্রিতে ক্লাউডে হোস্ট করার নিয়ম

পিসি বন্ধ থাকলেও বটকে ২৪ ঘণ্টা চালিয়ে রাখার জন্য নিচের যেকোনো প্ল্যাটফর্ম ব্যবহার করতে পারেন:

1. **Hugging Face Spaces (সবচেয়ে সহজ ও ফ্রি):**
   - Hugging Face-এ গিয়ে **New Space** তৈরি করুন (SDK: Docker সিলেক্ট করুন)।
   - প্রজেক্টের ফাইলগুলো আপলোড করুন এবং Settings > Variables-এ আপনার `.env` এর ভ্যালুগুলো যোগ করে দিন। এটি ২৪/৭ ফ্রিতে চলবে।
2. **Render.com (Free Background Worker):**
   - গিটহাবে কোড পুশ করে Render-এ "Background Worker" হিসেবে ডিপ্লয় করতে পারেন।
3. **Oracle Cloud Always Free VPS:**
   - ওরাকল আজীবন ফ্রি ক্লাউড ভিপিএস দেয়। সেখানে স্ক্রিপ্টটি `systemd` সার্ভিস হিসেবে ব্যাকগ্রাউন্ডে চালিয়ে রাখলে নিরবচ্ছিন্নভাবে চলবে।
